# 地方ポツン AUTO v0.7 COMPLETE

## 実装
- レース予約
- 15/10/5分前スナップショット
- 5分前候補固定（後から書き換えない）
- レース結果取得・1〜3着照合
- 永続SQLite (/var/data/potun.db)
- 完了レース数、候補3着内率、スコア帯別成績API
- /api/tick を外部Cronから定期実行可能

## 重要
Render Freeだけではサービスの常時起動を保証できません。
`/api/tick` を外部Cronから1分間隔程度で呼ぶか、常時稼働プランを使用してください。
また、RenderのPersistent Diskが利用できないプランでは `/var/data` 永続化は成立しません。
このv0.7は「データを蓄積して検証する基盤」であり、まだ機械学習モデルを自動再学習して本番スコアへ反映する版ではありません。
まず固定式のまま十分なレース数を集め、アウト・オブ・サンプルで重みを検証する前提です。
